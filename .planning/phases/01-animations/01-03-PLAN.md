    Page transitions in Next.js App Router are best implemented by wrapping page content in
    a motion.div with exit/enter variants. In layout.tsx, import AnimatePresence and wrap children.

    However, App Router layouts are Server Components by default and AnimatePresence requires
    'use client'. The solution: create a thin wrapper client component inline.

    In `src/app/layout.tsx`:

    1. Add at the TOP of the file (before RootLayout):
       ```tsx
       'use client' directive is NOT added to layout — instead add a small inline provider:
       ```
       
       Actually — Do this correctly for App Router:
       Create a `<PageTransitionWrapper>` component INSIDE layout.tsx as a sub-component
       with 'use client' at the top of a new file, OR add the wrapper in its own file.

       Best approach: Add to `src/app/layout.tsx` a named import from a new client module.
       
       BUT since layout.tsx is used as-is, the simplest correct approach:
       - ADD `'use client'` to layout.tsx is WRONG (breaks server metadata exports).
       
       Correct App Router approach:
       Create `src/app/_components/page-transition.tsx`:
       ```tsx
       'use client'
       import { AnimatePresence, motion } from 'framer-motion'
       import { usePathname } from 'next/navigation'

       export function PageTransition({ children }: { children: React.ReactNode }) {
         const pathname = usePathname()
         return (
           <AnimatePresence mode="wait">
             <motion.div
               key={pathname}
               initial={{ opacity: 0, y: 8 }}
               animate={{ opacity: 1, y: 0 }}
               exit={{ opacity: 0, y: -8 }}
               transition={{ duration: 0.25, ease: 'easeInOut' }}
             >
               {children}
             </motion.div>
           </AnimatePresence>
         )
       }
       ```

       Then in `src/app/layout.tsx`:
       - Add import: `import { PageTransition } from './_components/page-transition'`
       - Wrap `{children}` in `<PageTransition>`:
         ```tsx
         <PageTransition>
           <OfflineBanner />
           {children}
           <InstallPrompt />
         </PageTransition>
         ```
       Actually OfflineBanner and InstallPrompt should stay outside the page transition.
       Correct nesting:
       ```tsx
       <PostHogProvider>
         <OfflineBanner />
         <PageTransition>
           {children}
         </PageTransition>
         <InstallPrompt />
       </PostHogProvider>
       ```

    **Sticky nav scroll effect (GSAP):**
    Since the `<header>` is inside `src/app/page.tsx` (not in layout), add the scroll effect there.
    
    In `src/app/page.tsx`, the header is:
    ```tsx
    <header className="fixed top-0 left-0 right-0 z-50 bg-white/98 backdrop-blur-md border-b border-gray-100">
    ```
    Extract the header to a new client component `src/app/_components/site-header.tsx`:
    - 'use client'
    - Props: `user` (same type as HeroSection)
    - Copy header JSX verbatim
    - Add GSAP scroll effect:
      ```tsx
      const headerRef = useRef<HTMLElement>(null)
      useEffect(() => {
        if (typeof window === 'undefined') return
        const ctx = gsap.context(() => {
          ScrollTrigger.create({
            start: 80,  // start after 80px scroll
            onUpdate: (self) => {
              if (!headerRef.current) return
              if (self.progress > 0) {
                // Scrolled: reduce height, increase shadow
                gsap.to(headerRef.current, { height: 64, boxShadow: '0 4px 24px rgba(0,0,0,0.08)', duration: 0.4, ease: 'power2.out', overwrite: 'auto' })
              } else {
                // At top: restore
                gsap.to(headerRef.current, { height: 80, boxShadow: 'none', duration: 0.4, ease: 'power2.out', overwrite: 'auto' })
              }
            },
          })
        })
        return () => ctx.revert()
      }, [])
      ```
    - Apply `ref={headerRef}` to the `<header>` element.
    - In page.tsx add import `import { SiteHeader } from './_components/site-header'` and replace
      `<header ...>...</header>` with `<SiteHeader user={user} />`.
