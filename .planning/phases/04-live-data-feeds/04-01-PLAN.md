  <action>
    Create `src/lib/ai/live-risk-ingestion.ts` implementing `ingestLiveRiskFactors()`.

    **Structure:**
    ```typescript
    import { prisma } from '@/lib/prisma'
    import { decodeGeohash } from '@/lib/geo/geohash'

    const INDIA_BBOX = '68.18,37.09,97.40,8.07'  // NW corner then SE: minLon,maxLat,maxLon,minLat
    const TTL_MS = 6 * 60 * 60 * 1000             // 6-hour expiry for live factors

    export async function ingestLiveRiskFactors(): Promise<{ factorsCreated: number }>
    ```

    **Step 1 — Load zones:** Query `prisma.coverageZone` (distinct geohash), decode each with `decodeGeohash` to get centroid lat/lng.

    **Step 2 — Batch weather + flood (single parallel Promise.all):**
    - Weather: `GET https://api.open-meteo.com/v1/forecast?latitude={lats}&longitude={lngs}&current=weathercode,precipitation,windspeed_10m&forecast_days=1`
    - Flood: `GET https://flood-api.open-meteo.com/v1/flood?latitude={lats}&longitude={lngs}&daily=river_discharge,river_discharge_p25,river_discharge_p75&forecast_days=1`
    - Both support comma-separated lat/lng for multiple zones in one call.
    - **IMPORTANT:** Normalize responses to arrays: `Array.isArray(res) ? res : [res]` — single-coord returns object, multi-coord returns array.

    **Step 3 — Per-zone: delete stale live factors then create fresh ones:**
    ```typescript
    // Delete non-manual factors that haven't expired yet (prevents accumulation)
    await prisma.riskFactor.deleteMany({
      where: {
        geohash,
        source: { not: null },  // null = manual, never auto-delete manual
        expiresAt: { gt: new Date() },
      },
    })
    ```
    Then create WEATHER/STORM factor if wmoSeverity(code) > 0, and FLOOD factor if floodSeverity(q, p25, p75) > 0. Set `source: 'open-meteo'` and `expiresAt: new Date(Date.now() + TTL_MS)`.

    **WMO severity function (inline, not exported):**
    ```typescript
    function wmoSeverity(code: number): number {
      if (code >= 95) return 0.9   // thunderstorm
      if (code >= 80) return 0.65  // violent rain showers
      if (code >= 65) return 0.55  // heavy rain
      if (code >= 61) return 0.35  // moderate rain
      if (code >= 51) return 0.18  // drizzle
      if (code === 45 || code === 48) return 0.12  // fog
      return 0
    }
    // category: code >= 80 ? 'STORM' : 'WEATHER'
    ```

    **Flood severity function (inline, not exported):**
    ```typescript
    function floodSeverity(q: number | null, p25: number | null, p75: number | null): number {
      if (!q || !p25 || !p75 || q <= p25) return 0
      if (q <= p75) return 0.2
      return Math.min(0.3 + ((q - p75) / (p75 + 1)) * 0.5, 1.0)
    }
    ```

    **Step 4 — EONET India scan (one call, not per-zone, wrapped in try/catch — non-critical):**
    ```
    GET https://eonet.gsfc.nasa.gov/api/v3/events/geojson?status=open&days=7&bbox=68.18,37.09,97.40,8.07
    ```
    EONET category → RiskCategory map:
    ```typescript
    const EONET_MAP: Record<string, string> = {
      severeStorms: 'STORM',
      floods:       'FLOOD',
      wildfires:    'WILDFIRE',
      earthquakes:  'EARTHQUAKE',
      landslides:   'WEATHER',
    }
    ```
    For each feature, extract `geometry.coordinates` — handle both Point `[lng,lat]` and LineString `[[lng,lat],...]` (take first pair for line). Find nearest decoded zone within 1.5° (~165 km) using `Math.hypot(dLat, dLng)`. Create RiskFactor with `severity: 0.7`, `source: 'eonet'`.

    **Step 5 — Optional OWM enrichment:**
    ```typescript
    const OWM_KEY = process.env.OPENWEATHER_API_KEY
    if (OWM_KEY) {
      for (const zone of decoded) {
        // Sequential per-zone (not batchable in OWM One Call)
        const res = await fetch(
          `https://api.openweathermap.org/data/3.0/onecall?lat=${zone.lat}&lon=${zone.lng}` +
          `&exclude=hourly,daily,minutely&appid=${OWM_KEY}`
        ).then(r => r.json()).catch(() => null)
        const alerts = (res as OWMResponse | null)?.alerts ?? []
        if (alerts.length > 0) {
          await prisma.riskFactor.create({
            data: {
              geohash: zone.geohash,
              category: 'STORM',
              severity: 0.75,
              source: 'owm',
              expiresAt: new Date(Date.now() + TTL_MS),
            },
          })
          factorsCreated++
        }
      }
    }
    ```
    OWM alerts mean a national weather service has issued a formal alert — severity 0.75 is appropriate.

    Define internal types:
    ```typescript
    interface OpenMeteoCurrentResponse {
      current?: { weathercode?: number; precipitation?: number; windspeed_10m?: number }
    }
    interface FloodDailyResponse {
      daily?: {
        river_discharge?: (number | null)[]
        river_discharge_p25?: (number | null)[]
        river_discharge_p75?: (number | null)[]
      }
    }
    interface EONETFeature {
      geometry?: { type: string; coordinates: number[] | number[][] }
      properties?: { categories?: Array<{ id: string }> }
    }
    interface OWMResponse {
      alerts?: Array<{ event: string; description: string }>
    }
    ```

    Do NOT wrap the entire function in a single try/catch. Weather and flood are critical (let errors propagate). Only EONET and OWM have per-block try/catch.
